🔐 Encryption-Decryption Program

A simple Python-based application for encrypting and decrypting text using basic algorithms. This project demonstrates the fundamental concepts of data security and cryptography in an easy-to-understand way.

📌 Features

- Encrypt any message using a custom key or predefined method.
- Decrypt encrypted messages with the correct key.
- Command-line interface for user interaction.
- Beginner-friendly and easy to customize.

🧠 Concepts Used

- String manipulation
- Basic cryptographic principles
- Functions and conditionals
- User input handling

💻 Technologies

- Python 3.x

🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/encryption-decryption.git
   ```
2. Navigate to the project directory:
   ```bash
   cd encryption-decryption
   ```
3. Run the script:
   ```bash
   python encrypt_decrypt.py
   ```

📂 Example Usage

```bash
Enter a message to encrypt: Hello Brian
Enter a key: 3
Encrypted message: Khoor Euldq
Decrypted message: Hello Brian
```
